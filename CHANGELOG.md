# Changelog

## 1.0.1

- Publish the extension publicly on the VS Code Marketplace.
- Add links to the source code and issue tracker to the Marketplace page.

## 1.0.0

- First release on the VS Code Marketplace and Open VSX.
- Run PHREEQC on the current input file from the editor title bar, the Explorer context menu or `Ctrl+F5`, and stop a running job.
- Finds PHREEQC under `C:\Program Files\USGS` automatically, or uses the folder set with **Select PHREEQC Installation Folder…**.
- Opens the output or selected output after a run.
- File icons for PHREEQC input and output files, and highlighting for output and database files.
